Hi! My name is Fabian Huber. I am a Game & Graphics Programmer.

I specialize in Computer Graphics and low-level systems for video games. I studied Games Programming and Normal Programming™. I enjoy reinventing the wheel and am currently working on my game, using a homemade engine.

Projects

Machtou Pichtou Defenders: Slip and Slide

Game made during the Epic Game Jam 2026 over one weekend using a custom C engine developed by a team member.

Software Rasterizer

Project made to understand better how GPUs work, and get a better feeling of how rasterization works.

Bachelor Thesis - Voxel Path Tracing

Final project of my studies at SAE Institute Geneva. Implemented Voxel Path Tracing in a Vulkan compute shader using the Jai programming language. The thesis document was made in Typst.

OpenGL - Deferred PBR Renderer

A deferred PBR renderer made in C++ with OpenGL. Implements Image-Based Lighting, glTF format loading, GPU-compressed textures, Normal Maps, Cascaded Shadow Maps, Bloom and SSAO.
